# SemanticDocument

[中文](./semantic-document.md) | [English](./semantic-document.en.md)

该 schema 目前是占位。预期概念包括 Page、Block、TextSpan、BoundingBox、Figure、Table、Equation、Citation 与 SourceMapping。字段尚未决定。

见 [`.agents/notes/proposed/architecture/2026-09-03-semantic-document-canonical-model.md`](../../.agents/notes/proposed/architecture/2026-09-03-semantic-document-canonical-model.md)。

语言包可以在跟踪此 schema 之后持有便利类型。它们不是独立真源。
