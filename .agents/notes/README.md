# Agent Note

[中文](./README.md) | [English](./README.en.md)

Agent Note 替代单独的 ADR 树。它们合并 RFC、ADR、理由、提案生命周期与被否决的替代方案。

路径：`.agents/notes/<lifecycle>/<class>/yyyy-mm-dd-topic-title.md`（中文主文件）与 `yyyy-mm-dd-topic-title.en.md`（英文伴侣）。

生命周期：`proposed`、`implemented`、`rejected`、`archived`。

类别：`feature`、`bug-fix`、`simplification`、`architecture`、`process`、`testing`。

新建前先检索现行 note。见本目录 [`AGENTS.md`](AGENTS.md)。配对规则：[`docs/development/bilingual.md`](../../docs/development/bilingual.md)。
