# Agent Notes

[中文](./README.md) | [English](./README.en.md)

Agent Notes replace a separate ADR tree. They combine RFC, ADR, rationale, proposal lifecycle, and rejected alternatives.

Path: `.agents/notes/<lifecycle>/<class>/yyyy-mm-dd-topic-title.md` (Chinese primary) and `yyyy-mm-dd-topic-title.en.md` (English companion).

Lifecycles: `proposed`, `implemented`, `rejected`, `archived`.

Classes: `feature`, `bug-fix`, `simplification`, `architecture`, `process`, `testing`.

Search active notes before creating a new one. See [`AGENTS.md`](AGENTS.en.md). Pairing rules: [`docs/development/bilingual.md`](../../docs/development/bilingual.en.md).
